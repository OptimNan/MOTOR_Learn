## 简介 | Introduction

本仓库用于学习和记录电机相关知识，包括但不限于：

- 直流电机 (DC Motor)
- 步进电机 (Stepper Motor)
- 无刷电机 (Brushless DC Motor / BLDC)
- 交流感应电机 (AC Induction Motor)
- 永磁同步电机 (Permanent Magnet Synchronous Motor / PMSM)

## 目录 | Contents

- 电机原理 (Motor Principles)
- 驱动电路 (Drive Circuits)
- 控制算法 (Control Algorithms)
- 代码示例 (Code Examples)
