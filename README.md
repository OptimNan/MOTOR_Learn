## 扫一扫 / QR Code Scanner

本项目包含一个基于浏览器的二维码扫描功能（扫一扫）。

**使用方式：** 用浏览器打开 [`scan.html`](scan.html)，点击"开始扫描"，允许摄像头权限后将二维码对准取景框即可识别。

This project includes a browser-based QR code scanner.

**Usage:** Open [`scan.html`](scan.html) in a browser, click **开始扫描** (Start Scan), grant camera permission, and point the viewfinder at any QR code or barcode.
