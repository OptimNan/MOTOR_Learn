# MOTOR_Learn

电机学习仓库 | Electric Motor Learning Repository

## 简介 / Introduction

本仓库用于记录和整理电机相关知识，包括直流电机、交流电机、步进电机和无刷电机等。

This repository collects notes and resources for learning about electric motors, including DC motors, AC motors, stepper motors, and brushless motors.

## 内容目录 / Contents

- **直流电机 (DC Motors)** — 工作原理、驱动方式、调速方法
- **交流电机 (AC Motors)** — 感应电机、同步电机基础
- **步进电机 (Stepper Motors)** — 全步/半步驱动、细分控制
- **无刷电机 (BLDC Motors)** — FOC 控制、ESC 驱动
- **电机控制算法 (Control Algorithms)** — PID、FOC、SVPWM

## 快速开始 / Getting Started

克隆仓库后，按电机类型浏览各子目录中的笔记和示例代码。

Clone the repository and browse the subdirectories by motor type for notes and example code.

```bash
git clone https://github.com/OptimNan/MOTOR_Learn.git
```
